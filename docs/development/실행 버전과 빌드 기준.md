Vue 3.5.43·Vite 8.3.2·Node 24.21.0·ECharts 6.1.0에 **Three.js 0.186.1**을 잠금 파일로 추가했다. 3D 모델은 `services/factory-console/src/scene3d/`의 코드 형상이며 Blender/GLB 설치·변환이 필수 단계가 아니다. 브라우저 WebGL/그래픽 가속을 사용하고 2D SVG 대체 보기를 제공한다.

현재 로컬 수동 제어는 Python 3.12 + Vite 실행기다. 서버/DB를 Compose에 두고 호스트 Vite를 5174로 띄울 때 `FACTORY_SIMULATOR_PYTHON`을 유효한 Python 경로로 설정한다. Windows 전용 up은 Vite 5173과 Python 경로를 준비한다. 정적 Nginx/preview에는 실행기가 없다. [다른 컴퓨터 안내](<../../가상 제조공장 실시간 통합 관제 시스템 - 다른 컴퓨터 실행·개발 안내.md>)를 따른다.

새 partsSupply/traffic 메시지는 수집·관제의 최신 검증기가 필요하므로 화면만 업데이트하지 않는다. 최신 회귀 결과는 Python 58·콘솔 19 통과와 Vue 빌드이며, 기존 S09 지연 수치는 최신 3D 성능 검증이 아니다. 이 문서 아래 배포 출처·무결성·S단계 결과는 당시 기록을 보존한다.

## 공식 배포와 무결성

- [Spring Boot 4.1.1 시스템 요구사항](https://docs.spring.io/spring-boot/4.1/system-requirements.html): Java 21은 허용 범위이며 Maven 최소 요구는 3.6.3이다.
- [Spring Boot 빌드 구성](https://docs.spring.io/spring-boot/4.1/reference/using/build-systems.html): starter와 BOM 의존성 관리의 기준.
- [Apache Maven 배포](https://maven.apache.org/download.cgi): Maven 3.10.0 정식 배포와 SHA-512 확인.
- [Apache Maven Wrapper](https://maven.apache.org/tools/wrapper/): Wrapper가 고정 배포본을 실행하는 방식.

Wrapper 스크립트는 [공식 Maven Central의 3.3.4 only-script 배포본](https://repo.maven.apache.org/maven2/org/apache/maven/wrapper/maven-wrapper-distribution/3.3.4/)에서 추출했다. 제공된 SHA-1은 전송 손상 확인에 사용했으며 더 강한 서명 검증을 했다고 주장하지 않는다. Maven ZIP은 Apache 공식 SHA-512와 일치함을 확인했고, 계산한 SHA-256을 Wrapper 설정에 넣어 최초 다운로드를 검증하게 했다.

```text
Maven 3.10.0 ZIP SHA-256
1f6d9909266510f039f59aa0e13dcd2c66da85f043e56276e41f2918f8bddaff
```

only-script의 Unix 실행은 unzip이 필요하다. unzip이 없을 때 ZIP 대신 tar.gz를 받는 경로는 같은 ZIP 체크섬을 사용할 수 없으므로 이 프로젝트의 안내 환경은 unzip을 요구한다. 체크섬을 제거해서 우회하지 않는다. mvnw/mvnw.cmd의 Apache 라이선스 헤더를 유지했다.

이미지는 [images.lock.json](../../infrastructure/images.lock.json)과 실제 Compose/Dockerfile에 tag@sha256로 고정했다. 버전 변경 시 두 위치를 함께 갱신한다. stable 태그를 쓰는 Nginx도 digest로 내용이 고정돼 자동 갱신하지 않는다. Ubuntu 빌드 이미지의 unzip은 Maven Wrapper의 ZIP 무결성 확인에 필요하다. 패키지 저장소의 unzip 설치까지 별도 OS 패키지 잠금/완전한 바이트 단위 빌드 재현을 주장하지 않는다.

선택적인 macOS arm64 도구는 [local-tools.lock.json](../../infrastructure/local-tools.lock.json)과 prepare-dev-tools.py를 따른다. Node·Lima·Compose는 공식 배포 체크섬과 일치함을 확인했다. macOS Buildx는 공식 GitHub release asset digest와 일치함을 확인했다(배포 checksums.txt에는 이 macOS 파일이 없었음). Docker CLI 아카이브는 공식 HTTPS로 받고 계산한 SHA-256을 고정했다. 독립된 벤더 서명 검증까지 수행했다고 쓰지 않는다.

Vue는 npm ci로 잠금 의존성을 설치한다. Python은 현재 제삼자 의존성이 없다. 선택적인 Lima VM/다운로드 캐시 위치와 임시 DB 저장 한계는 [전체 실행 안내](../../infrastructure/README.md)에 있다. 기존 기술 스택 변경이나 MSA용 브로커/클러스터 추가는 없다.

## S06 최소 연결의 빌드 기준

2026-10-05 S06에서도 Java21/Boot4.1.1/Maven/PG17.11·Python3·Vue3/JavaScript/Vite와 이미지 고정값을 유지했다. Spring Servlet 비동기 WriteListener와 브라우저 EventSource, Node 내장 테스트를 사용하며 새 의존성/잠금 파일 변경/DB DDL은 없다.

# UI 색상 기준

> 사용자 지정 · 2026-10-05 · 실제 Vue 앱과 독립 샘플 GUI에 공통 적용

**흰색 바탕에 네이비 글씨를 사용한다. 색이 필요한 강조·선택·상태·차트는 네이비부터 파란색 계열로 통일한다.** 앞으로 만드는 지도·태그 상세·버퍼·품질·알람 화면도 이 기준을 따른다.

| 용도 | 색상 |
|---|---|
| 화면·카드·공장 지도 배경 | 흰색 `#ffffff` |
| 제목·본문·핵심 수치 | 네이비 `#172b4d` |
| 보조 글씨 | 청색을 띤 네이비 `#475b7a` |
| 버튼·선택·활성 강조 | 파란색 `#245ac4` |
| 보조 상태·경계 강조 | 청색 `#416baf` |
| 선택 배경·점유 슬롯 | 옅은 파란색 `#dfeaff` |
| 안내·예약 배경 | 아주 옅은 파란색 `#f5f8ff` |
| 구분선·테두리 | 옅은 청색 `#cbd8ed` / `#dbe5f3` |

흰색과 옅은 파란색 배경 위의 글씨는 네이비로 유지한다. 안내창과 알람도 다른 색 계열로 바꾸지 않는다. 모달 뒤의 가림막·그림자는 투명한 네이비를 사용할 수 있다.

상태는 색상만으로 판단하지 않는다. RUNNING/IDLE/BLOCKED/DOWN 이름을 함께 표시하고, 예약은 점선, 점유는 채움, 장애/미확인은 테두리·아이콘·굵기로 보완한다. 정상 상태를 보이는 파란색이 서버 준비와 제조 데이터 LIVE를 같은 뜻으로 만들지 않는다. 기존 상태/연결/슬롯 계약은 유지한다.

적용 파일: `services/factory-console/src/style.css`, 두 앱의 HTML theme-color, `factory-gui/styles.css`, 샘플 JS가 만드는 SVG의 색상. 후속 Vue 업무 화면에도 같은 팔레트를 적용한다.

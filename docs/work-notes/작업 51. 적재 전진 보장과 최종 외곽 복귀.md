# 작업 51. 적재 전진 보장과 최종 외곽 복귀

2026-10-10

## 원인과 수정

사용자가 AGV-002의 적재 후진을 지적했다. 앞선 수정에서 길이 100 이하의 구간 전체에 후진 최적화를 허용해 적재 상태와 접안 이탈을 구분하지 못했다. 기존 정상 3대 기록에서 차량·차체·구간을 중복 제거한 적재 후진 구간 12개를 재현했다. 단순히 3D 모델의 앞뒤 표시가 잘못된 문제가 아니라 실제 운동 계획의 오류였다.

- MOVING 상태에서는 호출부가 후진 허용을 넘겨도 후진할 수 없도록 운동 프로파일에서 차단한다. 적재 차량은 정지 상태에서 진행 방향으로 회전한 뒤 전진한다.
- 빈 차량의 TO_PICKUP/RETURNING, 재료 접안점 출발, 첫 구간, 길이 100 이하인 경우만 제한적 후진을 허용한다. 교차로와 중간 구간에는 적용하지 않는다.
- 초기 계획뿐 아니라 우회·양보 경로에도 같은 규칙을 적용한다. 모델 전면과 차체 전면은 모두 +x이며 화면의 회전 부호 변환과 일치한다.

## 마지막 복귀 요구

사용자는 모든 작업을 마친 AGV가 맨 마지막에만 바깥으로 돌아 초기 위치에 복귀하도록 요청했다.

모든 차체가 RESULT이고 활성 운송이 없으며 차량들이 정지했을 때 AGV-002, AGV-001 순으로 외곽 복귀를 배정한다. 초기 위치에 있는 차량은 건너뛴다. (845,650) → (0,650)을 지나 각 initialPosition으로 복귀하며, 이때 내부 지름길로 경로를 재계획하지 않는다. 한 대씩 복귀시켜 공장 입구에서 서로 마주치지 않도록 한다.

생산 중에는 현장 대기/다음 작업 배차를 유지한다. 출고 접안점을 잠시 비우는 이동은 최종 주차 복귀와 다르다. 오른쪽 대기점은 (780,260)/(780,340)으로 조정해 외곽 통로와 안전 여유를 확보했다. 부품 AMR은 사용자가 요청한 AGV 초기 위치 복귀 대상에서 제외한다.

관제는 `최종 복귀 → 초기 위치`를 표시한다. AGV가 모두 초기 위치에 도착하기 전에는 데모 drained와 RUN_FINISHED를 허용하지 않는다. 부품 차량을 숨기는 화면에서도 y=650 외곽 통로와 차량 안전 영역이 바닥 밖으로 나가지 않도록 바닥·통로 표시 범위를 확장했다.

## 검증

- Python 51개 테스트 통과. 매 tick 적재 차량의 이동 벡터와 차체 방향의 내적이 양수인지 확인한다. 정지 회전, 안전거리, 장애물, 가감속, 정상/장애, Bay 용량 변화, 100/500ms tick, 적재 양보·우회에도 적용한다.
- 최종 복귀는 모든 차체 RESULT/활성 운송 없음 조건을 만족하며 외곽 모서리 두 곳을 포함하는지 검사한다. 완료 시 AGV 초기 좌표와 일치하는지 검사한다.
- Node 15개 테스트 통과. 최종 복귀와 임시 대기 이동 라벨을 구별하고 3D 바닥이 외곽 통로를 포함하는지 확인했다. Vue 빌드 통과.
- 오프라인 정상 3대: 598개 스냅샷, 4,186개 차량군 보간 표본, 적재 구간 관측 1,005건 전진 조건 통과. 모두 GOOD/PASS. 첫 전량 출고 관측 187.1초, 마지막 외곽 주차까지 298.0초.
- P0 5대: 1,083개 스냅샷, 7,581개 보간 표본, 적재 구간 관측 3,355건 전진 조건 통과. 만석·장애·복구·부품 운송 단계 모두 통과. 전량 출고 첫 관측 429.1초, 주차 포함 540.5초.
- 종료 위치: AGV-001 (-90,260), AGV-002 (-90,420). 두 시나리오 모두 충돌 없이 종료했다. 차량 중심 안전거리 기준 63, 관측 최소 80 이상.

작업 50의 시간은 근처 대기에서 종료한 값이다. 이번 시간에는 사용자가 추가 요청한 외곽 최종 복귀가 포함되므로 총 소요 시간을 단순 성능 비교하지 않는다. 기존 기록·증거 파일은 보존하고 `forward-*`와 `lane-v4-forward-*`로 새 증거를 기록한다.

재현:

```sh

scripts/console.sh test
PYTHONPATH=services/factory-simulator .build-cache/simulator-venv/bin/python scripts/verify-lane-traffic.py --policy 4 --label forward
.build-cache/tools/node/node-v24.21.0-darwin-arm64/bin/node scripts/verify-3d-motion.mjs .build-cache/lane-validation-v4-forward/normal.ndjson --require-forward --require-final-home
.build-cache/tools/node/node-v24.21.0-darwin-arm64/bin/node scripts/verify-3d-motion.mjs .build-cache/lane-validation-v4-forward/p0.ndjson --require-forward --require-final-home
```

실제 연결 실행 `run-20261010-d6f336bea38b4ae9935c4d9ba1878a07`을 Chrome에서 시작하고 AGV-002의 ASM-01 출발, ASM-02 운반·접안을 직접 확인했다. 세 차체 출고 뒤 AGV-002가 외곽 통로로 먼저 복귀하고 AGV-001이 뒤이어 복귀하는 장면을 확인했다. `final-outer-return.jpg`에 경로와 최종 복귀 표시를 보존한다.

실제 연결 실행도 두 AGV의 초기 위치 주차 뒤 FINISHED가 됐다. 692개 사건의 원본 바이트·순번·해시가 Python, 수신 DB, 관제 DB에서 모두 일치했고 전달 대기는 0건이다. 실제 연결 스냅샷의 적재 구간 관측 1,005건이 전진 조건을 만족하고 외곽 복귀/최종 주차 검증도 통과했다. `forward-connected-render-verification.json`, `lane-v4-forward-connected-verification.json`, `final-home-completed.jpg`에 결과를 남겼다. 새 실행부터 적용하며 이전 관측 기록은 변경하지 않는다.

# 작업 45. Bay 후퇴와 설비 상태 및 AGV 목적지 표시

2026-10-10 · 2차 화면에 대한 사용자 피드백 반영

## 변경

- 새 교통 실행에서 Bay의 본체와 접안 위치를 함께 80 모델 단위 뒤로 이동했다. 설비 본체와 Bay 본체 사이의 열린 폭은 71 → 151이며, 차량 반경·여유 거리를 제외한 중심 주행 폭은 17 → 97이다. 차량 2대가 비켜갈 공간을 확보했다. 실제 미터 단위는 아니다.
- 부품 보관·접안 구역도 100 단위 뒤로 이동해 Bay와 간섭하지 않게 했다. AGV-002 주차 위치, AMR 주차 위치 및 바닥 경계를 조정했다.
- 운송 경로의 접안 끝점을 새 위치와 일치시키고 이동 시간은 종전 설정 속도에 맞춰 다시 계산한다. 충돌 영역과 3D 배치는 동일한 실행 설정을 읽는다. 이미 등록한 과거 실행의 배치는 바꾸지 않는다.
- ASM-01 / ASM-02 / QC-01 이름 아래에 대기, 작업 중(남은 시간), 작업 완료(픽업 대기·다음 Bay 만석·차량 대기), 고장·정지 플래그를 표시한다. 완료는 실제 작업이 끝났고 차체가 설비에 남아 있는 경우다. 인계가 끝나면 대기로 돌아간다.
- AGV/AMR 이름 아래에는 현재 운송 단계에 따라 픽업 장소, 상차 위치, 운반 목적지, 하차 위치, 복귀 주차 지점을 표시한다. 양보 중에도 목적지를 유지한다. 과거 교통 미적용 실행은 그 실행의 설정된 home을 표시한다.
- Bay 라벨은 각각 BAY-ASM-01 / BAY-ASM-02 / BAY-QC-01로 구분했다. 상태 카드의 텍스처는 값이 바뀔 때만 갱신한다. 화면상 최소 글자 크기를 확보하고, 카드 충돌 시 위치를 조정하며 연결선으로 원래 대상과 연결한다. 확대·축소·회전 후에도 같은 기준을 적용한다.

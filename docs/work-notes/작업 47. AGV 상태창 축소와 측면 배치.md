# 작업 47. AGV 상태창 축소와 측면 배치

2026-10-10 · 상태창이 AGV를 가리는 사용자 피드백 반영

- AGV/AMR 상태창을 화면 기준 124×34.875px로 고정해 확대 시 큰 카드로 늘어나지 않게 했다. 내부 여백을 줄이고 제목·상태 두 줄을 유지했다.
- 차량 중심의 화면 오른쪽에 배치한다. 차체와 적재물의 회전에 무관한 외곽 영역을 화면에 투영해 상태창이 차량 위에 놓이지 않게 한다. 화면 가장자리·다른 상태창과 충돌하면 왼쪽 또는 위아래의 빈 위치를 선택한다.
- 짧은 연결선으로 차량과 상태창을 연결한다. 다른 설비 상태창도 차량의 화면 영역을 피한다. 공간이 전혀 없으면 카드를 숨겨 차체 가림을 막으며 대상 선택 상세는 계속 사용할 수 있다.
- Chrome 실제 관제 화면에서 기본·확대·평면·회전 시점 확인, 브라우저 오류 없음. Vite 빌드와 diff 공백 검증 통과. 시뮬레이션 로직 변경 없음.

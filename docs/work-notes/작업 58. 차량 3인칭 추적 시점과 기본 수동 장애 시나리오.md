# 작업 58. 차량 3인칭 추적 시점과 기본 수동 장애 시나리오

2026-10-11

## 요청과 반영

각 AGV와 AMR을 단순 지도 확대보다 자세히 볼 수 있는 차량 중심 3인칭 추적 시점을 추가했다. 추가 요청에 따라 현재 3대 수동 장애 복구를 일반 관제의 기본 장애 시나리오로 정리했다.

- 차량 선택: 전체 공장 / AGV-001 / AGV-002 / AMR-001. 기본 차량 시점은 3인칭이며 AGV는 기존 전면 1인칭으로 전환 가능하다.
- 차량 뒤쪽 위 사선에서 원근 카메라로 차체 전체, 바퀴, 적재물과 주변 통로를 보여준다. 실제 관측 및 기존 보간 위치를 따라가며 시뮬레이터 주행 경로/물리 상태를 변경하지 않는다.
- 방향 변화는 최단 각도로 부드럽게 따라간다. ±π 경계에서 카메라가 한 바퀴 돌아가는 현상을 방지한다.
- 드래그로 차량 주변 시점을 바꿀 수 있고 휠로 거리를 조절한다. 이동/회전 후에도 사용자가 설정한 상대 각도를 유지한다. 시점 초기화 및 전체 공장 복귀 버튼을 제공한다.
- 설비가 카메라와 차량 사이를 가리면 카메라 거리를 줄인다. 추적 중 상태 라벨 대신 좌측 카드에 차량 ID, 목적지/상태, 차체 또는 부품 키트 적재 ID를 표시한다.
- 기본 시나리오는 `demo-maintenance`이며 표시명은 **장애 시나리오 · 3대 / 수동 복구**다. 자동 복구 P0 검증 데모는 일반 실행 선택지에서 제외했다. 기존 P0 CLI/검증용 실행 경로는 유지한다.
- 기본 장애의 실제 제어 흐름은 작업 56/57에서 검증한 수동 방식 그대로다: 장애 → 사용자 현장 점검 시작 → 사용자 조치 완료 → 2초 동작 확인 → 남은 작업 재개. 신규 실행은 사용자 조작 없이는 자동 복구하지 않는다. 정상 생산 1대/3대 선택지는 유지한다.

## 검증

- 콘솔 전체 테스트 19개 통과, 프로덕션 빌드 성공. 기존 대형 청크 경고만 있다.
- 실제 적재 차량 모델의 3D 경계가 4방향·2크기·3화면비에서 카메라 화면 내부에 들어오는지 검사했다. 기존 1인칭 및 각도 경계/정지 상태도 검증했다.
- 실행 중인 `run-20261010-b4ed27ce84d8414ba4631d0537ae3041`에서 AMR 복귀 추적, 적재 AGV 운반 추적, 드래그 각도 변경, 휠 거리 조절, 1인칭 전환을 Chrome에서 확인했다. 해당 실행을 중단/재시작하지 않고 화면만 조작했다.

# 작업 9. 흰색과 네이비 UI 색상

> 사용자 추가 요청 · 2026-10-05 · S01 이후 UI 색상 조정 · S02는 미착수

화면을 흰색 바탕, 네이비 글씨, 네이비~파란색 강조로 통일했다. 실제 Vue 기본 앱과 기존 factory-gui 샘플에 모두 적용했고, 샘플 공장 지도·스마트태그 창·버퍼·차트의 색도 맞췄다.

CSS는 화면의 바탕·글씨·선·버튼 모양을 정한다. 샘플의 지도/차트는 JavaScript가 SVG 도형을 만들기 때문에 그 안에 직접 지정된 색상도 함께 변경했다. 두 HTML의 theme-color도 흰색으로 맞췄다.

한 계열의 색으로 상태를 구분하므로 색 이외의 표시가 필요하다. 예약의 점선과 점유의 채움을 유지하고, 차단/장애는 텍스트와 테두리를 함께 사용한다. 업무 상태 계산과 버퍼 예약 규칙은 이번 색상 작업의 변경 대상이 아니다.

앞으로 화면을 개발할 때도 같은 기준을 따르도록 [UI 색상 기준](<../development/UI 색상 기준.md>)을 만들고 기획서·해설집·각 GUI 안내에 연결했다.

Vue 배포 빌드가 통과했고 실제 Chrome에서 두 화면의 흰색 바탕·네이비 글씨·파란색 강조를 확인했다. 검증은 이 빌드와 두 화면 확인으로 한정했다. 스타일 변경에 별도 자동 테스트를 만들거나 DB/전체 기능 테스트를 반복하지 않는다. 확인한 화면 캡처는 실제 Vue의 preview-foundation.jpg와 샘플의 preview-white-blue.jpg에 남긴다.

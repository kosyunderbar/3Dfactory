# 작업 52. AGV와 ASM 상세 모델 시안

2026-10-10

## 목적과 범위

사용자는 PARTS-ASM 기능 확장 전에 기존 3D 모델의 현실감을 높이고, 먼저 확인할 수 있는 시안을 요청했다. 밝은 바닥과 블루·네이비 색감을 유지해 AGV-002와 ASM-01 한 세트의 별도 검토 화면을 만들었다.

접속: `http://127.0.0.1:5174/?preview=equipment`

이번 작업은 외형과 인계 동작의 설계 시안이다. 실제 설비 도면 기반 CAD, 실제 공장 데이터와 연결된 디지털 트윈, 충돌 검증을 마친 생산 시뮬레이션을 의미하지 않는다. 기존 관제 모델·배차·운동 계획·최종 외곽 복귀는 이번 작업에서 변경하지 않았다. 시안 확인 후 전체 공장 모델에 반영할 범위를 결정한다.

## 모델과 조작

- AGV: 둥근 차체 외장, 전후면 조명, 범퍼, 전면 센서, 비상정지 버튼, 휠, 통풍 패널, 볼트와 적재 롤러.
- 차체: 운반 팔레트와 지지부, 창문, 도어 구분, 손잡이, 휠과 전면등.
- ASM: 같은 높이의 이송 롤러, 고정 클램프, 두 관절 로봇팔과 케이블 표현, 제어반, 표시등, 조작 패널, 후면 안전 펜스와 입구 센서.
- 밝은 바닥의 통로·설비 경계 표시, 금속 재질, 환경광과 접지 그림자.
- 전체 / AGV 상세 / ASM 상세 / 평면 시점, 회전·확대, 재생·일시정지, 타임라인과 단계 선택.

25초 예시 시퀀스: 접안(0–4초) → 차체와 팔레트 인계(4–9초) → 고정·조립(9–18초) → 고정 해제와 회수(18–25초). 차체가 이동하기 전에 로봇팔을 바깥으로 물리고, 차량은 접안 후 정지한다. 조립 동작은 형태 검토를 위한 애니메이션이며 실제 로봇의 역기구학이나 공정 검증은 포함하지 않는다.

## 검증

- `scripts/console.sh build` 성공. 기존 대형 청크 경고는 남아 있다.
- `scripts/console.sh test`: 15개 통과. 최초 실행은 샌드박스의 로컬 포트 제한으로 launcher 테스트가 실패했으며, 포트 사용이 허용된 실행에서 전체 통과했다.
- Chrome에서 접안·인계·조립·회수 구간을 재생하고 25초 종료와 다시 재생 버튼을 확인했다.
- 조립 중 일시정지, 단계 이동, 차량·설비 확대와 평면 시점을 확인했다. 브라우저 콘솔 오류 없음.
- 모델 수정 중 팔레트와 타이어의 높이, 인계 중 로봇 대기 자세, 작업 중 관절의 차체 간격을 조정했다.
- 검토 화면: `docs/development/3d-review/equipment-detail-review.png`.

## 변경 파일

- `services/factory-console/src/EquipmentReview.vue`: 검토 페이지와 조작 UI.
- `services/factory-console/src/scene3d/equipment-models.js`: 상세 설비 모델.
- `services/factory-console/src/scene3d/equipment-review-scene.js`: 조명·카메라·시안 애니메이션과 자원 정리.
- `services/factory-console/src/main.js`: `preview=equipment` 진입점의 지연 로딩.

현재 상태: 사용자 외형·동작 검토 대기. 전체 관제 모델 교체는 아직 하지 않았다.

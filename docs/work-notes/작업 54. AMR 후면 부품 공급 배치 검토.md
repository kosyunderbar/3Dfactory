# 작업 54. AMR 후면 부품 공급 배치 검토

2026-10-11

사용자는 ASM 뒤편에 AMR 부품 공급 구역을 두는 방향에 동의했으며, 실제 반영 전에 UI 배치를 먼저 보여달라고 요청했다.

## 확인용 화면

`http://127.0.0.1:5174/?preview=amr`

별도 정적 Three.js 시안을 추가했다. 실제 완료된 정책 4 공장의 설정을 기준 파일로 복사해 기존 ASM/QC/Bay/입출고 구역의 위치를 유지한다. 메인 관제, Python 시뮬레이터, 배차·재고·이벤트 계약은 변경하지 않는다. 생산 실행이나 REST/SSE 연결을 생성하지 않으며 배포 컨테이너도 갱신하지 않았다.

- 왼쪽 위: 부품 창고와 AMR 대기·복귀 자리.
- ASM-01·02 뒤편: `PARTS-ASM-01`, `PARTS-ASM-02` 공급대.
- 후면 가로 통로에서 각 공급대 앞 정차 지점으로 분기. 청록색은 제안 AMR 통로, 옅은 파랑은 기존 차체 통로.
- 전체 배치, 부품 구역 확대, 평면 배치, 이름 표시/숨기기, 회전·확대를 제공한다.
- 차량·키트는 배치 예시이며 실시간 생산이나 재고로 표시하지 않는다. 페이지 상단에 '배치 검토 · 미적용'을 명시한다.

## 시안 좌표

공장 좌표이며 실측 미터 단위가 아니다. 모두 정식 설정과 별도인 제안값이다.

| 대상 | x | y |
|---|---:|---:|
| 부품 창고 중심 | -87.5 | -140 |
| 창고 앞 AMR 정차 | 0 | -140 |
| AMR 대기·복귀 | -90 | -240 |
| PARTS-ASM-01 공급대 중심 | 150 | -80 |
| PARTS-ASM-02 공급대 중심 | 350 | -80 |
| 각 공급대 앞 AMR 정차 | 150 / 350 | -140 |
| AMR 가로 통로 | 0 ~ 350 | -220 |

바닥의 위쪽 경계를 -300으로 확장했다. 공급대와 ASM 사이 점선은 향후 공급 연결을 검토할 구간이며, 키트 인계 장치나 로봇 도달 범위가 검증됐다는 뜻은 아니다. 창고·통로·도킹 간격과 설비 후면 접근 방식은 사용자 배치 확인 후 실제 운송 규칙 구현 단계에서 확정한다.

## 확인

- 콘솔 빌드 성공. 기존 대형 청크 경고만 존재.
- Chrome에서 전체/후면 확대/평면 보기를 직접 확인. AMR 라벨이 차량을 가리지 않도록 화면 배치를 조정하고, 평면 보기에서는 부품 공급대 라벨을 모델 아래로 이동했다.
- 브라우저 오류/경고 없음.
- 정적 배치 검토이므로 실제 AMR 운송·부품 소비·재보급·충돌 시뮬레이션의 성공을 주장하지 않는다.
- 캡처: `docs/development/3d-review/amr-layout-overview.png`, `amr-layout-rear.png`, `amr-layout-top.png`.

현재 상태: 사용자 배치 검토 대기. 승인 후 부품 소모/재보급, 작업 시작 조건, AMR 배차 및 실제 경로·충돌 영역 구현을 진행한다.
